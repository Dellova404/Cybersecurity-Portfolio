## 🚀 Módulos & Projetos Práticos Concluídos

### 🔹 Curso 4: Tools of the Trade: Linux and SQL

* **Administração e Permissões no Linux (Bash):**
* Gerenciamento de permissões de diretórios e arquivos confidenciais via terminal (`chmod`, `chown`).
* Aplicação do princípio do Menor Privilégio (*Least Privilege*) para controle de acessos corporativos.


* **Investigação de Logs com SQL:**
* Construção de queries com filtros avançados (`SELECT`, `WHERE`, `AND`, `OR`, `LIKE`) para investigar tentativas de login fora de horário e ataques de força bruta.
* Cruzamento de tabelas com `JOIN` para auditar máquinas desatualizadas e correlacionar incidentes de segurança.



### 🔹 Curso 5: Assets, Threats, and Vulnerabilities (Atual)

* **Inventário de Ativos de Rede e Matriz de Sensibilidade (NIST ID.AM):**
* Mapeamento da superfície de ataque e inventário de dispositivos conectados a uma rede local (Home Office).
* Classificação de ativos com base nos níveis de mercado (*Restricted, Confidential, Internal-only, Public*).
* Análise de riscos de movimentação lateral e segmentação para vetores IoT (Smart TVs, impressoras e estações de trabalho).
* Documento disponível na pasta: `05-assets-threats-and-vulnerabilities/home-network-asset-inventory/`

## 🛠️ Tecnologias e Frameworks Aplicados

* **Sistemas Operacionais & CLI:** Linux (Ubuntu/Debian), Shell Bash, Linha de Comando.
* **Bancos de Dados & Análise:** SQL (Structured Query Language), Auditoria e Filtragem de Logs.
* **Frameworks & Modelos:** NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover), Tríade CIA (Confidencialidade, Integridade e Disponibilidade).
* **Gestão de Risco:** Classificação da Informação, Identificação de Vulnerabilidades (CVE/CVSS) e Triagem de Incidentes.
